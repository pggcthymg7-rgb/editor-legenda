# Backlog: finalização do editor (sessão noturna)

Pedido: terminar o projeto em modo autônomo:
- auditoria de segurança e código;
- layout profissional;
- legenda atrás da pessoa, opcional;
- mais fontes estilizadas grátis;
- edição individual de cada palavra, com escala horizontal e vertical;
- comparação com os editores de ponta;
- PWA e desktop finalizados.

- [x] 1. Auditoria inicial: segurança, código quebrado, congruência entre Mac e PWA.
- [x] 2. Fontes: biblioteca grande de fontes grátis (OFL) e estilizadas, com seletor visual por categoria.

- [x] 4. Layout profissional, igual nos dois (desktop e PWA):

  - timeline embaixo, com régua, playhead, blocos arrastáveis e redimensionáveis, zoom e atalhos.
- [x] 5. Paridade com os editores de ponta (CapCut, Premiere, Submagic):

  - dividir na agulha;
  - atalhos.
- [x] 6. Legenda atrás da pessoa:

- [x] 7. Auditoria final: segurança, testes, builds, e2e (desktop e iPhone), `npm audit`.
